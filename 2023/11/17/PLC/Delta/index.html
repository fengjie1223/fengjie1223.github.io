    Delta PLC 高级应用技术

    本文档针对台达（Delta）PLC 高级应用功能进行详细说明，涵盖 PID 控制、各类中断、模拟量处理、通信功能及浮点运算等核心模块，结合实操要点与参数设置，适用于具备基础 PLC 操作经验的技术人员，用于指导现场调试与程序开发。

    一、PID 控制

    1.1 PID 控制原理

    PID（比例-积分-微分）控制是台达 PLC 中常用的闭环控制算法，通过对比设定值（SV）与实际反馈值（PV）的偏差（EV=SV-PV），利用比例（P）、积分（I）、微分（D）三个环节的协同作用，自动调节输出值（MV），使被控量（如温度、压力、流量）稳定在设定值附近，适用于温度控制、液位控制、速度控制等连续过程控制场景。

    1.2 台达 PLC PID 参数设置

    台达 PLC 支持两种 PID 编程方式：一是利用专用 PID 指令（如 DVP 系列的 PIDL、PIDR 指令），二是通过 PLC 编程软件（如 WPLSoft）的 PID 向导进行参数配置，推荐新手使用向导配置，高效且不易出错。核心参数如下：

    • 比例增益（Kp）：决定偏差响应的灵敏度，Kp 越大，偏差纠正速度越快，但过大会导致系统震荡；Kp 过小，系统响应迟缓，无法快速达到设定值。

    • 积分时间（Ti）：消除静态偏差，Ti 越小，积分作用越强，静态偏差消除越快，但过大会导致系统超调量增大；Ti 过大，积分作用微弱，无法彻底消除静态偏差。

    • 微分时间（Td）：抑制系统震荡，提前预判偏差变化趋势，Td 越大，微分作用越强，系统稳定性越好，但过大会导致输出响应迟缓；Td 过小，微分作用不足，无法有效抑制震荡。

    • 其他参数：采样时间（Ts，建议根据被控对象特性设置为 0.1~10s）、比例带宽（PB，与 Kp 成反比）、积分分离值、输出上下限等。

    1.3 实操要点

    1. 反馈值（PV）需来自模拟量输入（如温度传感器、压力变送器），需提前完成模拟量校准，确保数据准确；

    2. 首次调试时，建议采用“先比例、后积分、再微分”的调试方法：先将 Ti 设为无穷大、Td 设为 0，逐步增大 Kp 至系统出现轻微震荡，再减小 Kp 至震荡消失；随后逐步减小 Ti，消除静态偏差；最后逐步增大 Td，提升系统稳定性；

    3. 对于非线性、大滞后被控对象（如温度控制），可启用台达 PLC 内置的 PID 自整定功能，自动计算最优参数；

    4. 输出值（MV）可对应模拟量输出（如变频器频率、调节阀开度）或开关量输出（如继电器通断），需根据执行器类型设置输出类型。

    二、定时中断

    2.1 定时中断原理

    定时中断是台达 PLC 中一种主动触发的中断方式，通过设定固定的中断周期（如 10ms、100ms），PLC 会每隔设定时间，暂停当前主程序执行，优先执行中断子程序，执行完成后再返回主程序继续运行。适用于需要高精度定时控制的场景，如高频采样、精准计时、同步控制等（精度高于普通定时器 T 指令）。

    2.2 台达 PLC 定时中断设置（以 DVP 系列为例）

    台达 DVP 系列 PLC 定时中断主要通过 WPLSoft 软件配置，结合中断子程序编程，步骤如下：

    1. 打开 WPLSoft 软件，新建工程，选择对应 PLC 型号（如 DVP-ES2、DVP-EH3）；

    2. 在“程序编辑区”切换至“中断子程序”界面，新建定时中断子程序（中断编号可选择，如 INT0~INT7，不同型号 PLC 中断数量不同）；

    3. 在“系统寄存器”中配置定时中断参数：设定中断周期（单位：μs 或 ms，如 10000μs=10ms）、启用中断允许位，选择中断触发方式（上升沿、下降沿或持续触发）；

    4. 在中断子程序中编写需要精准定时执行的逻辑（如数据采样、计数器清零、输出触发），子程序长度不宜过长，避免影响主程序执行；

    5. 在主程序中启用定时中断（置位中断允许标志位），中断触发后，PLC 自动跳转至中断子程序执行。

    2.3 注意事项

    1. 中断周期不可设置过短（如小于 1ms），否则会导致主程序无法正常执行，出现 PLC 卡顿、程序报错等问题；

    2. 同一时间建议只启用 1~2 个定时中断，多个定时中断同时启用时，需合理分配中断优先级，避免中断冲突；

    3. 中断子程序中禁止使用长时间延时指令（如 TON、TOF 指令），禁止修改主程序中关键变量的值（如需修改，需做好逻辑判断，避免数据混乱）；

    4. 若需暂停定时中断，可复位中断允许标志位；若需清除中断状态，可使用中断清除指令。

    三、计数中断

    3.1 计数中断原理

    计数中断是台达 PLC 基于计数器的中断方式，通过设定计数器的目标值（中断触发值），当计数器的当前值达到设定目标值时，PLC 立即暂停主程序，执行对应的计数中断子程序，执行完成后返回主程序。适用于高精度计数控制场景，如工件计数、脉冲计数、位置定位等（精度高于普通计数器 C 指令）。

    台达 PLC 计数中断支持两种计数方式：内部计数（对 PLC 内部脉冲信号计数）和外部计数（对 PLC 外部输入端子的脉冲信号计数，如编码器脉冲）。

    3.2 台达 PLC 计数中断设置（以 DVP-EH3 为例）

    1. 新建工程，选择对应 PLC 型号，切换至“中断子程序”界面，新建计数中断子程序（中断编号与定时中断区分，如 INT8~INT15）；

    2. 在“系统寄存器”中配置计数中断参数：选择计数通道（如 CH0~CH3，不同型号通道数量不同）、计数方式（增计数、减计数、增减计数）、中断触发值（目标计数次数）、计数脉冲输入端子（外部计数时设置）；

    3. 在计数中断子程序中编写触发后的逻辑（如工件计数完成报警、设备停机、计数器清零）；

    4. 主程序中启用计数中断（置位中断允许标志位），同时初始化计数器当前值，启动计数（外部计数需确保输入端子脉冲信号稳定）；

    5. 当计数器当前值达到设定触发值时，触发计数中断，执行子程序，执行完成后，计数器当前值可自动清零或保持（根据参数设置）。

    3.3 注意事项

    1. 外部计数时，输入脉冲信号的频率需匹配 PLC 计数通道的最大响应频率（如 DVP-EH3 最大计数频率可达 100kHz），避免脉冲丢失，导致计数不准确；

    2. 中断触发值需根据实际需求设置，避免过大或过小，同时需预留一定余量，防止计数误差；

    3. 多个计数中断同时启用时，需设置中断优先级，优先执行关键场景的中断子程序（如紧急停机相关的计数中断）；

    4. 若需修改计数中断触发值，需先暂停计数中断，修改完成后再重新启用，避免中断误触发。

    四、IO 中断

    4.1 IO 中断原理

    IO 中断（又称外部中断）是台达 PLC 由外部输入端子的信号变化触发的中断方式，当指定的外部输入端子出现上升沿、下降沿或电平变化时，PLC 立即暂停主程序，执行对应的 IO 中断子程序。适用于需要快速响应外部信号的场景，如紧急停止、外部触发、信号检测等（响应时间通常在 μs 级）。

    台达 PLC 常用的 IO 中断类型：上升沿中断（输入信号从 OFF 变为 ON 时触发）、下降沿中断（输入信号从 ON 变为 OFF 时触发）、双边沿中断（上升沿和下降沿均触发）。

    4.2 台达 PLC IO 中断设置（以 DVP-ES2 为例）

    1. 新建工程，选择 PLC 型号，切换至“中断子程序”界面，新建 IO 中断子程序，分配中断编号（如 INT0 对应 X0 端子）；

    2. 在“系统寄存器”中配置 IO 中断参数：选择中断触发端子（如 X0、X1）、触发方式（上升沿、下降沿、双边沿）、启用中断允许位；

    3. 在 IO 中断子程序中编写外部信号触发后的逻辑（如紧急停机、设备启动、信号采集），子程序需简洁，避免占用过长执行时间；

    4. 主程序中启用 IO 中断（置位中断允许标志位），同时确保外部输入信号稳定，避免干扰导致误触发（可在输入端子并联滤波电容）。

    4.3 注意事项

    1. 不同型号 PLC 支持的 IO 中断端子数量不同（如 DVP-ES2 支持 X0~X3 端子作为中断输入），需根据 PLC 型号选择合适的中断端子；

    2. 外部输入信号需避免抖动（如按钮、传感器信号），可通过硬件滤波（并联电容）或软件滤波（在子程序中增加延时判断）消除抖动，防止中断误触发；

    3. IO 中断响应优先级最高，当 IO 中断与定时中断、计数中断同时触发时，优先执行 IO 中断子程序；

    4. 紧急停止场景建议使用 IO 中断，确保外部紧急信号触发后，PLC 能立即响应，避免设备故障或人员安全问题。

    五、模拟量

    5.1 模拟量基础

    台达 PLC 的模拟量功能主要用于处理连续变化的物理量（如温度、压力、流量、速度等），通过模拟量输入模块（AI）将外部传感器的模拟信号（如 010V 电压信号、420mA 电流信号）转换为 PLC 可识别的数字信号（二进制数），再通过主程序逻辑处理后，由模拟量输出模块（AO）将数字信号转换为模拟信号，控制执行器（如变频器、调节阀、伺服驱动器）动作。

    台达 PLC 常用模拟量信号类型：

    • 模拟量输入（AI）：420mA 电流信号（常用，抗干扰能力强）、010V 电压信号（适用于短距离传输）、-10~10V 双极性电压信号（适用于正负变化的物理量）；

    • 模拟量输出（AO）：420mA 电流信号、010V 电压信号，与输入信号对应，用于控制执行器的输出量。

    5.2 模拟量模块配置与校准

    5.2.1 模块配置

    台达 PLC 模拟量模块需与主机匹配（如 DVP-ES2 系列主机搭配 DVP04AD-E2 模拟量输入模块、DVP04DA-E2 模拟量输出模块），配置步骤如下：

    1. 将模拟量模块与 PLC 主机正确连接（通过总线连接器连接，确保接线牢固）；

    2. 打开 WPLSoft 软件，在“工程设置”中选择“模块配置”，添加对应的模拟量输入/输出模块，设置模块地址（默认地址可修改，需与程序中地址对应）；

    3. 配置模拟量信号类型：在模块配置界面，选择每个通道的信号类型（如 AI 通道选择 420mA，AO 通道选择 010V），保存配置并下载至 PLC。

    5.2.2 模拟量校准

    模拟量模块使用前需进行校准，确保输入/输出信号的准确性，校准分为零点校准和满量程校准：

    1. 零点校准：将模拟量输入端子接入零点信号（如 420mA 信号接入 4mA，010V 信号接入 0V），在 WPLSoft 软件中执行零点校准指令，或通过 PLC 面板操作完成校准；

    2. 满量程校准：将模拟量输入端子接入满量程信号（如 420mA 信号接入 20mA，010V 信号接入 10V），执行满量程校准指令，保存校准参数；

    3. 校准完成后，可通过软件监控模拟量输入/输出值，确认数据是否准确（如 4mA 对应数字值 0，20mA 对应数字值 32767）。

    5.3 模拟量编程实操

    台达 PLC 模拟量编程核心是“模拟量信号与数字量信号的转换”，常用指令如下：

    • AIW 指令：读取模拟量输入值（如 AIW0 对应第一个 AI 通道的输入数字量，范围 0~32767）；

    • AOW 指令：写入模拟量输出值（如 AOW0 对应第一个 AO 通道的输出数字量，范围 0~32767）；

    • SCALE 指令：模拟量比例转换指令，将 AIW 读取的数字量转换为实际物理量（如将 420mA 对应的 032767 数字量，转换为 0~100℃的温度值）；

    • UNSCALE 指令：将实际物理量转换为模拟量输出数字量（如将 050Hz 的频率值，转换为 420mA 对应的数字量，控制变频器频率）。

    实操示例：读取温度传感器（420mA 信号，对应 0100℃）的温度值，控制变频器（420mA 信号，对应 050Hz）频率，温度越高，频率越高。

    5.4 注意事项

    1. 模拟量接线需采用屏蔽线，屏蔽层一端接地，避免干扰（尤其是电流信号，接线距离不宜超过 100m）；

    2. 模拟量模块需远离变频器、接触器等强电磁干扰设备，防止信号失真；

    3. 编程时需注意模拟量数字量与实际物理量的对应关系，避免比例转换错误；

    4. 定期对模拟量模块进行校准，尤其是环境温度变化较大的场景，确保测量精度。

    六、串口通信

    6.1 串口通信基础

    台达 PLC 内置串口通信接口（如 RS-232、RS-485），用于与外部设备（如触摸屏、变频器、传感器、电脑）进行数据交互，采用异步串行通信方式，核心是通过设定通信参数，实现 PLC 与外部设备的双向数据传输。

    台达 PLC 常用串口类型：

    • RS-232：点对点通信，传输距离短（≤15m），抗干扰能力弱，适用于 PLC 与电脑、触摸屏的近距离通信；

    • RS-485：多点通信（可连接 32 个从站），传输距离长（≤1200m），抗干扰能力强，适用于 PLC 与变频器、多个传感器的远距离通信。

    6.2 串口通信参数设置

    台达 PLC 串口通信参数需与外部设备保持一致，否则无法正常通信，核心参数如下，通过 WPLSoft 软件“系统寄存器”配置：

    • 波特率：常用 9600bps、19200bps、38400bps，需与外部设备波特率一致（波特率越高，传输速度越快，抗干扰能力越弱）；

    • 数据长度：常用 8 位（bit），即一个字节的数据；

    • 校验位：无校验（N）、奇校验（O）、偶校验（E），常用无校验或偶校验，需与外部设备一致；

    • 停止位：常用 1 位（bit），用于标识一个数据帧的结束；

    • 通信协议：常用 Modbus RTU、台达专用协议（如 DVP 协议），根据外部设备支持的协议选择。

    6.3 串口通信编程（以 RS-485 为例）

    台达 PLC 串口通信编程核心是使用通信指令，实现数据的发送与接收，常用指令如下：

    • RS 指令：串口通信控制指令，用于启动/停止串口通信，配置通信参数（可替代系统寄存器配置，灵活度更高）；

    • SEND 指令：串口数据发送指令，将 PLC 内部寄存器（如 D 寄存器）的数据发送至外部设备；

    • RECV 指令：串口数据接收指令，接收外部设备发送的数据，存储至 PLC 内部寄存器；

    • 校验指令：如 CRC 校验指令，用于验证接收数据的准确性，避免数据传输错误。

    实操示例：PLC 通过 RS-485 串口与变频器通信，发送频率设定值（存储在 D100 寄存器），接收变频器实际频率值（存储在 D101 寄存器），当实际频率与设定频率偏差过大时，触发报警。

    6.4 注意事项

    1. RS-485 通信需使用差分信号线（A、B 线），接线时需注意 A 接 A、B 接 B，避免接反，否则无法通信；

    2. 远距离通信时，需在 RS-485 总线两端并联终端电阻（120Ω），抑制信号反射，提升通信稳定性；

    3. 编程时需增加通信异常处理逻辑（如通信超时、数据校验错误），避免 PLC 因通信故障死机；

    4. 多个设备通信时，需为每个设备分配唯一地址（从站地址），避免地址冲突。

    七、网口通信

    7.1 网口通信基础

    台达中高端 PLC（如 DVP-EH3、DVP-SV2 系列）内置以太网接口（RJ45 接口），支持网口通信，采用 TCP/IP 协议，可实现 PLC 与电脑、触摸屏、其他 PLC、工业以太网设备（如交换机、路由器）的高速数据交互，传输速度远高于串口通信，适用于大型自动化系统、多设备联动、远程监控等场景。

    台达 PLC 网口通信常用协议：Modbus TCP、EtherNet/IP、台达 Ethernet 协议，其中 Modbus TCP 协议应用最广泛，兼容性强，可与各类支持 Modbus TCP 的设备通信。

    7.2 网口通信参数设置

    1. IP 地址设置：PLC 网口需设置唯一的 IP 地址（如 192.168.1.100），子网掩码（默认 255.255.255.0）、网关（根据网络拓扑设置），需与通信网络中的其他设备（如电脑、触摸屏）在同一网段；

    2. 协议设置：在 WPLSoft 软件“系统寄存器”中，选择网口通信协议（如 Modbus TCP），设置端口号（Modbus TCP 默认端口号 502）；

    3. 网络连接：将 PLC 网口通过网线连接至交换机或电脑，确保物理连接正常（PLC 网口指示灯常亮或闪烁，表明连接正常）；

    4. 测试连接：在电脑上通过 ping 命令（如 ping 192.168.1.100）测试与 PLC 的网络连接，若能 ping 通，表明网络参数设置正确。

    7.3 网口通信编程（以 Modbus TCP 为例）

    台达 PLC 网口通信编程需根据通信角色（主站/从站）编写程序，常用指令如下：

    • MB_TCP_MASTER 指令：Modbus TCP 主站指令，用于 PLC 作为主站，读取/写入从站设备（如其他 PLC、变频器）的数据；

    • MB_TCP_SLAVE 指令：Modbus TCP 从站指令，用于 PLC 作为从站，接收主站（如电脑、触摸屏）的读取/写入指令，返回对应数据；

    • Socket 指令：通用网口通信指令，用于自定义通信协议，实现 PLC 与其他设备的灵活通信（适用于高级用户）。

    实操示例：PLC 作为 Modbus TCP 主站，通过网口读取 3 台从站 PLC 的温度数据（存储在从站 D100 寄存器），存储至主站 D200、D201、D202 寄存器，通过触摸屏实时监控所有温度数据。

    7.4 注意事项

    1. IP 地址需唯一，避免与网络中其他设备冲突，否则会导致网口通信失败；

    2. 网口通信需确保网络稳定，避免网线松动、交换机故障等问题，远距离通信可使用光纤交换机；

    3. 编程时需设置通信超时时间，当通信超时（如超过 1s），触发异常处理逻辑（如重新连接、报警）；

    4. 远程监控场景中，需配置网关、路由器端口映射，确保外部设备能访问 PLC 网口（注意网络安全，避免非法访问）。

    八、浮点运算

    8.1 浮点运算基础

    浮点运算用于处理带有小数的数值（如 3.14、10.5），台达 PLC 支持 32 位浮点运算（单精度浮点型，符合 IEEE 754 标准），通过浮点运算指令，实现小数的加、减、乘、除、平方根、三角函数等运算，适用于需要高精度数值计算的场景，如流量计算、液位控制、位置定位、复杂算法实现等。

    台达 PLC 浮点型数据存储：采用两个连续的 D 寄存器存储一个 32 位浮点数（如 D100、D101 存储一个浮点数，D100 为低 16 位，D101 为高 16 位），编程时需注意寄存器的连续使用，避免数据覆盖。

    8.2 台达 PLC 浮点运算指令

    台达 PLC 浮点运算指令以“F”开头，区分于整数运算指令，常用指令如下：

    • FADD：浮点加法指令（如 FADD D100 D102 D104，将 D100/D101、D102/D103 存储的浮点数相加，结果存储在 D104/D105）；

    • FSUB：浮点减法指令；

    • FMUL：浮点乘法指令；

    • FDIV：浮点除法指令；

    • FSQRT：浮点平方根指令（如 FSQRT D100 D102，计算 D100/D101 浮点数的平方根，结果存储在 D102/D103）；

    • FABS：浮点绝对值指令（计算浮点数的绝对值）；

    • FTAN、FSIN、FCOS：浮点三角函数指令（正切、正弦、余弦）；

    • INT_F：整数转浮点指令（将整数转换为浮点数，如 INT_F D0 D100，将 D0 中的整数转换为浮点数，存储在 D100/D101）；

    • F_INT：浮点转整数指令（将浮点数转换为整数，舍去小数部分）。

    8.3 实操要点与注意事项

    1. 浮点运算前，需将整数转换为浮点数（使用 INT_F 指令），否则会导致运算错误（如整数 5 需转换为浮点数 5.0 后，才能与 3.14 进行运算）；

    2. 浮点运算结果需存储在两个连续的 D 寄存器中，编程时需预留足够的寄存器空间，避免数据覆盖；

    3. 浮点运算存在微小误差（如 0.1+0.2 可能不等于 0.3），高精度场景中，可通过扩大倍数（如将 0.1 转换为 1，运算后再除以 10）减少误差；

    4. 避免浮点运算结果为无穷大或NaN（非数字），如除数为 0，会导致运算异常，编程时需增加逻辑判断（如判断除数是否为 0）；

    5. 浮点运算指令执行时间比整数运算长，高频运算场景中，需合理分配程序执行时间，避免 PLC 卡顿。

    九、Modbus

    Modbus 是工业领域最常用的通信协议之一，分为 Modbus RTU 和 Modbus TCP 两种类型，台达 PLC 全面支持这两种协议，可作为主站或从站与外部设备（如变频器、触摸屏、传感器、其他 PLC）通信，实现数据的双向传输，兼容性强、操作简单，是台达 PLC 通信应用的核心协议。

    9.1 Modbus 协议基础

    Modbus 协议采用“主从通信”模式，即一个主站对应多个从站，主站发送指令，从站接收指令并响应（从站不可主动发送指令），核心是通过“功能码”区分不同的通信指令（如读取线圈、读取寄存器、写入寄存器等）。

    台达 PLC Modbus 常用功能码：

    • 0x01：读取线圈状态（对应 PLC 输出继电器 Y，如 Y0~Y17）；

    • 0x02：读取离散输入状态（对应 PLC 输入继电器 X，如 X0~X17）；

    • 0x03：读取保持寄存器（对应 PLC 数据寄存器 D，如 D0~D9999），最常用；

    • 0x04：读取输入寄存器（对应 PLC 模拟量输入寄存器 AIW，如 AIW0~AIW7）；

    • 0x05：强制单个线圈（控制 PLC 输出继电器 Y 通断）；

    • 0x06：预置单个保持寄存器（写入 PLC 数据寄存器 D），最常用；

    • 0x10：预置多个保持寄存器（批量写入 PLC 数据寄存器 D）。

    9.2 Modbus RTU 从站（重点）

    台达 PLC 作为 Modbus RTU 从站时，无需编写复杂的通信程序，只需正确配置串口参数和从站地址，即可响应主站的指令（如触摸屏、电脑作为主站，读取/写入 PLC 数据），实操步骤如下：

    1. 规划串口使用：选择 PLC 内置的串口（如 COM1 对应 RS-485，COM2 对应 RS-232），确认该串口未被其他功能占用（如未用于其他通信协议）；

    2. 配置串口通信参数：在 WPLSoft 软件“系统寄存器”中，设置该串口的波特率（如 9600bps）、校验位（如无校验）、数据长度（8 位）、停止位（1 位）；

    3. 选择通信协议：设置串口通信协议为“Modbus RTU”，确认与其通信的主站设备（如触摸屏）使用的是 RTU 协议（而非 ASCII 协议），两者协议必须一致；

    4. 设置从站地址：为 PLC 分配唯一的 Modbus RTU 从站地址（范围 1~247，默认地址为 1），主站需通过该地址识别 PLC；

    5. 确认配置并下载：将上述参数配置完成后，下载至 PLC，重启 PLC 使参数生效；

    6. 通信测试：主站（如触摸屏）设置相同的通信参数和从站地址，发送读取/写入指令，测试是否能正常与 PLC 通信（如触摸屏读取 PLC D100 寄存器的数据，或控制 Y0 输出）。

    关键说明：台达 PLC 作为 Modbus RTU 从站时，无需写任何通信相关的代码（例如 RS 指令、SEND/RECV 指令，或者置位通信标志等都不需要），参数配置完成后，PLC 会自动识别主站指令并响应。

    9.3 Modbus RTU 主站

    台达 PLC 作为 Modbus RTU 主站时，需编写通信程序，通过 Modbus RTU 主站指令，发送指令至从站设备，读取/写入从站数据，实操步骤如下：

    1. 配置串口参数：与从站配置一致（波特率、校验位、数据长度、停止位），设置主站自身的串口参数；

    2. 编写主站程序：使用台达 PLC 内置的 Modbus RTU 主站指令（如 MODBUS_RTU_MASTER），配置从站地址、功能码、寄存器地址、数据长度等参数；

    3. 数据处理：将从站读取的数据存储至 PLC 内部寄存器（如 D 寄存器），或将 PLC 内部数据写入从站寄存器，编写逻辑处理程序（如数据校验、异常报警）；

    4. 通信测试：连接主站与从站设备（RS-485 总线连接），运行程序，测试主站是否能正常读取/写入从站数据，排查通信故障。

    9.4 Modbus TCP 主站/从站

    Modbus TCP 协议基于以太网，传输速度快、距离远，台达 PLC 作为 Modbus TCP 主站/从站的配置与 Modbus RTU 类似，核心区别在于“通信参数设置为网口参数”：

    • Modbus TCP 从站：配置 PLC 网口 IP 地址、子网掩码、网关，设置协议为 Modbus TCP，端口号默认 502，分配从站地址，无需编写通信代码，主站（如电脑、触摸屏）通过网口访问 PLC；

    • Modbus TCP 主站：配置网口参数，编写主站程序（使用 MB_TCP_MASTER 指令），设置从站 IP 地址、端口号、功能码、寄存器地址等，实现与从站的高速通信。

    9.5 注意事项

    1. 主站与从站的通信参数（波特率、校验位、协议类型）必须完全一致，否则无法正常通信；

    2. 从站地址必须唯一，多个从站连接时，避免地址冲突；

    3. Modbus RTU 通信需注意 RS-485 接线（A 接 A、B 接 B），远距离通信需加终端电阻；

    4. 编程时需增加通信异常处理逻辑（如通信超时、数据校验错误），避免 PLC 因通信故障影响正常运行；

    5. 读取/写入寄存器时，需注意 Modbus 寄存器地址与 PLC 内部寄存器地址的对应关系（如 Modbus 保持寄存器地址 40001 对应 PLC D0 寄存器）。
